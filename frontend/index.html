      Comparison vs Steganalysis - what's the difference?
      
Comparison (this section) requires both the known cover and stego object and calculates
      exact differences - every changed value is known with certainty because both files are available.

      
Steganalysis (below) may only have a suspected object; it attempts to infer the presence
      of hidden data statistically, without ever seeing the original cover.

      
An embedding location is also not necessarily a changed location: if the existing bit already matched the
      bit being written, LSB replacement leaves that value untouched, so "positions written to" and "positions
      changed" are not the same set.
