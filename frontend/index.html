    Transfer and evidence checklist
        
    1. Party A encodes and downloads the PNG or WAV. Record payload size, package size, embedding capacity, LSB depth and start settings.
      2. 
        
    2. Send the downloaded file as an email attachment or another file-preserving transfer. Party B downloads it to a local folder and selects that file in Verify. The same-page shortcut is only a local demonstration.
      3. 
        
    3. Party B uses the agreed settings and trusted sender public key. Capture the verdict, hash match, signature result and extracted message. Export the verification log.
      4. 
        
    4. Use the Learning Objective short message, Project Overview large message, and your team's custom payload across your runs. Keep evidence of both PNG and WAV successes and failures.
    
        
    Capacity means usable embedding space, not the cover's disk size. The message plus metadata and signature must fit. Signing and hiding do not encrypt the message; a confidential label alone does not prove confidentiality.
