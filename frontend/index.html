PAIRS OF VALUES
Chi-square analysis
Tests adjacent value pairs such as 100/101. Each channel uses the stronger of its whole-channel tail score and the median usable-window tail score; the overall score is the median channel summary. A p-value is not the probability that a secret exists.
Run analysis to see measurements.


REGULAR / SINGULAR GROUPS
RS analysis
Measures changes in local smoothness after controlled bit flips, before and after flipping every LSB. The score is the Fridrich/Goljan/Du estimate of the fraction of samples affected by 1-LSB replacement, bounded to 0–1. It is not a probability.
Run analysis to see measurements.


REGIONAL EVIDENCE
Chi-square window results
Windows are consecutive values within each colour plane. Positions are zero-based, with the end excluded. Window size changes these regional results and can change the chi-square summary score or verdict. A single peak is not used for classification because scanning many windows produces chance high scores.
Run analysis to see measurements.
