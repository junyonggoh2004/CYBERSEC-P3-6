– chance this file carries hidden data
This is not a tampering check. Tampering is decided on Verify, where the signature and hashes either pass or fail.


PAIRS OF VALUES
Chi-square analysis
Tests adjacent value pairs such as 100/101. Each channel uses the stronger of its whole-channel and median-window tail score. A p-value is not the probability that a secret exists.
Run analysis to see measurements.


REGULAR / SINGULAR GROUPS
RS analysis
Measures changes in local smoothness after controlled bit flips, before and after flipping every LSB. The score estimates the fraction of values affected by 1-LSB replacement; it is not a probability.
Run analysis to see measurements.


CONSECUTIVE SAMPLE PAIRS
Sample-pair analysis
Estimates the share of samples whose lowest bit was replaced, from how neighbouring samples pair up in value. Chi-square is not used for audio: a clean recording already looks "embedded" to it.
